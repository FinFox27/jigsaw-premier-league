# JIGSAW Version 7

## New
- JIGSAW Intel tab with automatically generated competition banter and analysis.
- Club crests are shown on the Premier League and Predictions tables, with initials as a fallback if a crest cannot load.
- Pre-season page remains deliberately quiet rather than generating meaningless competitive banter.
- Updater now saves club crest URLs returned by football-data.org.
- Updater now derives the football-data.org season code from `data/config.json`, making future seasons easier to run.
- Historical data automatically resets when the configured season changes.

## Existing
- Prediction colours remain: green = actual higher/better than predicted, gold = exact, red = actual lower/worse than predicted.
